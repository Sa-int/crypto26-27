# Комп'ютерний практикум №2 — Криптоаналіз шифру Віженера

Бригада: ФБ-43, Горбонос О., Дрєпіна А. Варіант 2.

## Структура

```
code/       програми (vigenere.py — спільний модуль, task1…task4 — завдання практикуму)
data/       вхідні дані: variant2_cipher.txt (шифртекст), plaintext.txt (власний відкритий текст)
results/    таблиці, JSON і текстові результати роботи програм
artifacts/  графіки
report/     звіт (KP2_zvit.pdf)
```

## Запуск

Потрібні Python 3.9+ та matplotlib. Шляхи рахуються від розташування скриптів, тому
запускати можна з будь-якої папки. Порядок важливий (task2 використовує результати task1, task4 — task3):

```bash
cd code
python task1_research.py
python task2_period.py
python task3_key_recovery.py
python task4_key_error.py
```

Власний відкритий текст: `python prepare_text.py шлях/до/тексту.txt` (збереже `data/plaintext.txt`),
після чого знову запустити task1.

Частоти літер з КП1 можна підключити файлом `data/letter_freq_kp1.csv`
(рядки `літера,частота`); без нього використовуються типові частоти російської мови.
