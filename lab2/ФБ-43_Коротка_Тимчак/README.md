# Лабораторна 2 — Криптоаналіз шифру Віженера

**Бригада:** ФБ-43 — Коротка, Тимчак · **Варіант:** 4

Шифр Віженера над російським алфавітом із 32 літер (`ё → е`). Частоти мови беруться з корпусу першої лабораторної.

## Файли

- `lab2.py` — шифрування/розшифрування, індекс відповідності, пошук періоду (середній I блоків і статистика D_r для r ≤ 30), відновлення ключа, експеримент з помилкою в ключі. Друкує результати і записує їх у `results.txt`.
- `plaintext.txt` — власний відкритий текст (Л. Толстой, «Анна Каренина», ч. 4, гл. I; 2509 літер після нормалізації).
- `ciphertext_v4.txt` — шифртекст варіанта 4 (8061 літера).
- `decrypted_v4.txt` — розшифрований текст варіанта 4.
- `results.txt` — результати останнього запуску `lab2.py`.
- `lab2_Korotka_Tymchak.docx` / `.pdf` — звіт (протокол).

## Запуск

```bash
cd lab2/ФБ-43_Коротка_Тимчак
python3 lab2.py
```

Потрібен корпус `lab1/ФБ-43_Коротка_Тимчак/corpus.txt`.

## Основні результати

- Індекс відповідності падає з ростом довжини ключа: 0.0558 (ВТ) → 0.0444 (r=2) → 0.0327 (r=16), до 1/32 ≈ 0.0312.
- Період шифртексту: **r = 13** (середній I блоків 0.0541 проти ~0.0326 для інших r; D₁₃ = 456, D₂₆ = 416 при фоні ~250).
- Ключ: **громыковедьма**. Розшифрований текст починається зі слів «старминская школа чародеев пифий и травниц…».
- Помилка в одному символі ключа псує лише кожну 13-ту літеру (620 з 8061), кожну зсуває на 1.
