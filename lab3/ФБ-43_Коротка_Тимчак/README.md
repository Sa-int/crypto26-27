# Лабораторна 3 — Криптоаналіз афінної біграмної підстановки

**Бригада:** ФБ-43 — Коротка, Тимчак · **Варіант:** 4

Афінна підстановка біграм `Y = (aX + b) mod m²` над російським алфавітом із 31 літери (`ё → е`, `ъ → ь`, порядок `…шщьыэюя`), m² = 961.

## Файли

- `lab3.py` — розширений алгоритм Евкліда, обернений елемент, розв'язування лінійних порівнянь (з усіма розв'язками при gcd > 1), частоти біграм, перебір зіставлень 5 найчастіших біграм мови і шифртексту, автоматичний розпізнавач російської мови. Друкує результати і записує їх у `results.txt`.
- `ciphertext_v4.txt` — шифртекст варіанта 4 (5846 літер, копія `tasks/lab3/variants.utf8/04.txt`).
- `decrypted_v4.txt` — розшифрований текст варіанта 4.
- `results.txt` — результати останнього запуску `lab3.py`.
- `lab3_Korotka_Tymchak.docx` / `.pdf` — звіт (протокол).

## Запуск

```bash
cd lab3/ФБ-43_Коротка_Тимчак
python3 lab3.py
```

Потрібен корпус `lab1/ФБ-43_Коротка_Тимчак/corpus.txt` (для перевірки частот біграм мови).

## Основні результати

- П'ять найчастіших біграм шифртексту: **еш, еы, шя, ск, до**.
- 400 систем (20 пар біграм мови × 20 пар біграм шифртексту) → 175 різних кандидатів (a, b); 40 систем (пара «но», «то», різниця 155 = 5·31) розв'язків не мають.
- Розпізнавач: частка «о, а, е» ≥ 0.20 і частка «ф, щ, ь» ≤ 0.05. Його пройшов лише один кандидат.
- Ключ: **a = 390, b = 10** (зіставлення «ст» → «еш», «то» → «до»). Розшифрований текст — уривок зі статті З. Фрейда «Достоевский и отцеубийство»: «если правда что достоевский в сибири не был подвержен припадкам…».
