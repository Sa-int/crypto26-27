## Структура роботи

- `code/` — програмна реалізація лабораторної роботи та `.txt` файл з текстом
- `data/` — нормалізовані та згенеровані текстові послідовності
- `results/` — результати обчислень у форматі CSV
- `coolpink/` — скриншоти експериментів CoolPinkProgram
- `crypto_lab1_report.pdf` — звіт до лабораторної роботи

## Програмна реалізація

Програма виконує:

- нормалізацію російськомовного тексту;
- підрахунок частот символів;
- підрахунок частот біграм;
- обчислення H1 та H2;
- обчислення для біграм, що перетинаються та не перетинаються;
- експерименти А, Б, В;
- експерименти Г, Д;
- оцінювання надлишковості джерела.
